# ApexKite

ApexKite is a cloud-based, real-time data processing manager, offering auto-scaling and dynamic resource allocation on a unified platform.

With ApexKite, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/ApexKite.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

ApexKite is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
